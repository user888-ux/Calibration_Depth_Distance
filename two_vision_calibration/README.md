# two_vision_calibration

## 用于标定

### 使用方法
- 0.制作标定板。建议打印棋盘格菲林+铝板，然后把菲林摁实在铝板，排净空气，利用大气压力让菲林粘在铝板上面
- 1.连接相机
- 2.运行``python3 calibration_code/capture.py``
- 3.拍摄若干张照片，可以调曝光等参数来提高拍摄质量。建议有效的照片15~20张。我们是拍了48张只有16张有效
- 4.运行``python3 calibration_code/calibrate.py``
- 5.观察**立体重投影误差**，一般要小于0.5。如果很大的，考虑是不是左右角点的检测顺序不同
- 6.把结果文件(.yml和.npz)复制到你想要的地方
